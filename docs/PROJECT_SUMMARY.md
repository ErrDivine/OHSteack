## 技术架构

### 后端技术栈
- **框架**: Flask 3.0.3
- **数据库ORM**: SQLAlchemy 2.0.31
- **数据库迁移**: Flask-Migrate 4.0.7
- **用户认证**: Flask-Login 0.6.3
- **密码加密**: Flask-Bcrypt 1.0.1
- **表单处理**: WTForms 3.1.2 + Flask-WTF 1.2.1
- **Markdown**: markdown2 2.5.0
- **数据库驱动**: PyMySQL 1.1.1

### 前端技术栈
- **CSS**: 原生CSS（Apple设计风格）
- **JavaScript**: 原生ES6+
- **图标**: Font Awesome 6.4.0
- **字体**: Inter字体系列

### 部署技术栈
- **Web服务器**: Nginx
- **WSGI服务器**: Gunicorn 22.0.0
- **进程管理**: Supervisor
- **数据库**: MySQL 5.7+

## 使用说明

### 开发环境运行

```bash
# 1. 克隆项目
git clone <repository-url>
cd OHSteack

# 2. 运行设置脚本
bash scripts/setup.sh

# 3. 配置环境变量
nano .env

# 4. 启动开发服务器
source venv/bin/activate
flask run
```

### 生产环境部署

```bash
# 使用自动部署脚本
sudo bash scripts/deploy.sh

# 配置域名和SSL
sudo nano /etc/nginx/sites-available/ohsteack.conf

# 重启服务
sudo supervisorctl restart ohsteack
```
